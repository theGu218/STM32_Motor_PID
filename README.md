# STM32 舵机控制学习项目

> 观前提醒：该项目代码仅供个人学习使用，如有不足请见谅。

##  项目简介
现在还是学习的第一阶段。现在实现了基于 STM32 标准库的按键驱动舵机功能：每次按下按键，舵机转动固定角度。

##  开发环境与硬件
- **主控芯片**：STM32F103C8T6
- **开发工具**：Keil MDK
- **下载调试**：ST-Link
- **底层库**：STM32 标准外设库（SPL）

  
## 目前进度
- 现在是已经实现了配置定时器输出PWM驱动舵机，现在按下按键舵机就能转动固定角度

## 计划
- 未来计划是引入编码器，获取当前位置的速度和位置反馈，然后引入PID算法进行闭环控制
