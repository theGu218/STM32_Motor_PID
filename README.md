##  踩坑记录

### 2026.10.08 - L298N 突发短路与杜邦线熔断事故
- **情况**：在同时连接 7.4V 锂电池与电脑 USB（ST-Link）的情况下，尝试烧录代码。随后发现杜邦线瞬间大电流发热烧毁，L298N 板载 5V 稳压部分疑似击穿，STM32开发板倒是没出啥问题，但是L298N电桥不出意外应该是牺牲了。
- **排查过程**：等万用表到了再具体看看是什么情况。
- **原因**：目前原因尚不清楚，我感觉可能是锂电池的原因，7.4V 的电压太大，但是也可能不是，以后换南孚电池了，但是肯定不是 BOOT 引脚的问题。
- **后续处理**
  - 上电前先打表：接线完成后，必须先使用万用表蜂鸣档测试 VCC 与 GND 是否短路，确认无误再上电。
  - 尽量不使用套件中的劣质杜邦线供电，后续会更换具有过流保护功能的 TB6612 驱动模块。
- **下一步计划**：等新的L298N电桥到了再试一次，纵有疾风起，人生不言弃。
